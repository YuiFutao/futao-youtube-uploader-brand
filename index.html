Futao Video Uploader

個人用の動画アップロードツール

このアプリについて

Futao Video Uploader は、指定したフォルダ内の動画ファイルを YouTube へ連続アップロードするための、 コマンドライン形式のツールです。開発者本人が個人的な動画（旅行の記録など）を 自分の YouTube チャンネルへアップロードする目的のためだけに開発・使用しています。

一般公開されているウェブサービスではなく、第三者への提供や配布は行っていません。

使用している権限

YouTube Data API v3 の https://www.googleapis.com/auth/youtube.upload （動画のアップロード）スコープのみを使用します。
